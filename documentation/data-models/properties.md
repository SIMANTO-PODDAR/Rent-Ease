# Properties Collection (`all-properties`)

This collection stores all property listings created by Owners on the platform.

## Field Reference

| Field | Type | Description | Notes |
| --- | --- | --- | --- |
| `_id` | ObjectId | Unique identifier. | Auto-generated by MongoDB. |
| `title` | String | Title of the property. | |
| `description` | String | Long-form description. | |
| `location` | String | General location or address. | Used for regex search. |
| `propertyType` | String Enum | "Apartment", "House", "Room", "Studio", "Commercial". | |
| `rentPrice` | Number | Cost to rent. | |
| `rentType` | String Enum | "Monthly", "Weekly", "Daily". | |
| `bedrooms` | Number | Count of bedrooms. | |
| `bathrooms` | Number | Count of bathrooms. | |
| `size` | Number | Square footage. | |
| `amenities` | Array of Strings | Selected amenities (e.g., "Parking", "Lift", "Gym"). | |
| `extraFeatures` | Array of Strings | Selected extra features (e.g., "Furnished", "AC", "Pet Friendly"). | |
| `image` | String (URL) | URL of the property image hosted on ImgBB. | |
| `status` | String Enum | "Pending", "Approved", "Rejected". | Defaults to "Pending". |
| `rejectionFeedback` | String | Note provided by Admin upon rejection. | Max 250 characters. |
| `ownerId` | String | ID of the user who created the property. | References `user.id`. |
| `owner` | Object | Inline snapshot of the owner: `{ id, name, email }`. | |
| `createdAt` | Date String | ISO timestamp of creation. | |

## Status Lifecycle

- Properties begin in the **"Pending"** state. They are invisible to public search.
- An Admin reviews the property and updates the status to **"Approved"** (making it public) or **"Rejected"** (returning it to the owner with `rejectionFeedback`).
- If an Owner updates a property, its status automatically reverts to **"Pending"**, and `rejectionFeedback` is cleared.

For detailed access capabilities based on status, refer to the [Roles & Permissions](../roles/readme.md) documentation.
