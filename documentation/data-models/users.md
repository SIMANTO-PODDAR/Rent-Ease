# Users Collection (`user`)

The `user` collection is managed primarily by `better-auth` rather than the Express backend.

## Field Reference

| Field | Type | Description |
| --- | --- | --- |
| `id` | String | Unique string identifier generated by better-auth (not an ObjectId). |
| `name` | String | Full name of the user. |
| `email` | String | Email address. |
| `emailVerified` | Boolean | Whether the email has been confirmed. |
| `image` | String | Profile image URL (ImgBB or Google OAuth). |
| `createdAt` | Date | Timestamp of account creation. |
| `updatedAt` | Date | Timestamp of last account modification. |
| `role` | String Enum | "Tenant", "Owner", "Admin". (Defaults to "Tenant"). |

## Role Assignment

- All new users are created with the default role of **"Tenant"**.
- The `role` field was added as custom metadata via `better-auth` configuration in `src/lib/auth.js`.
- Admins can manually upgrade a user to an "Owner", allowing them to access the Owner Dashboard and create properties.

For full details on what each role can do, refer to the [Roles & Permissions](../roles/readme.md) documentation.
